# Truck Bhai

Clickable mobile prototype of Truck Bhai, a truck booking marketplace for Bangladesh with Shipper and Driver apps, English and Bengali.

Live app demo: https://yasir019.github.io/truck/

Admin panel demo: https://yasir019.github.io/truck/admin/

Install on a phone: open the link in Chrome (Android) and tap Install app, or in Safari (iPhone) tap Share, then Add to Home Screen.

This is a design prototype with sample data. Payments, camera and verification are simulated.
